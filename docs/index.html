데스크톱 위젯

바탕화면 우측 하단에 상주하는 캘린더 · 할 일 · 뽀모도로 위젯 (Windows)

주요 기능

  • 캘린더 — 월 달력에서 날짜를 클릭하면 그날의 일정 목록을 보고, 위젯에서 바로 일정을 추가합니다.
  • 할 일 — 마감일 기준으로 기한 초과 / 오늘 / 예정으로 묶어 보여주고, 추가 · 완료 · 삭제할 수 있습니다.
  • 포커스 — 집중과 휴식을 번갈아 진행하는 뽀모도로 타이머입니다.
  • Google 동기화 — Google 캘린더 및 Google Tasks와 양방향으로 동기화됩니다.
  • 항상 위 고정, 트레이 상주, Windows 시작 시 자동 실행을 지원합니다.

설치와 사용

개인용으로 만든 오픈소스 앱입니다. Node.js가 설치된 환경에서 저장소를 받은 뒤 npm install 과 npm start 로 실행합니다. Google 연동은 사용자 본인의 OAuth 클라이언트를 사용하며, 설정 방법은 저장소의 SETUP.md에 있습니다.
