개인정보처리방침

데스크톱 위젯 (캘린더 · 할 일 · 포커스) · 최종 수정일: 2026년 8월 28일

1. 요약

이 앱은 사용자의 PC에서만 실행되는 데스크톱 프로그램입니다. 개발자가 운영하는 서버가 없으며, 사용자의 데이터를 수집하거나 전송받지 않습니다. 모든 데이터는 사용자의 컴퓨터와 사용자 본인의 Google 계정 사이에서만 오갑니다.

2. 접근하는 정보

사용자가 Google 로그인에 동의한 경우에만 아래 정보에 접근합니다.

  • Google 캘린더 일정 (calendar.events) — 일정을 위젯에 표시하고, 위젯에서 만든 일정을 캘린더에 추가하거나 삭제하기 위해 사용합니다.
  • Google Tasks 할 일 (tasks) — 할 일을 위젯에 표시하고, 추가 · 완료 · 삭제를 반영하기 위해 사용합니다.

이메일 본문, 연락처, 파일 등 그 밖의 어떤 정보에도 접근하지 않습니다.

3. 정보의 저장 위치

  • 일정 · 할 일의 사본과 앱 설정은 사용자 PC의 %APPDATA%\desk-widget\ 폴더에만 저장됩니다.
  • Google 로그인 토큰은 Windows의 자격 증명 보호 기능(DPAPI)으로 암호화하여 같은 위치에 저장됩니다.
  • 이 정보는 사용자의 컴퓨터를 떠나지 않으며, 개발자를 포함한 제3자에게 전송되지 않습니다.

4. 제3자 제공 및 광고

수집하는 정보가 없으므로 제3자에게 판매 · 제공 · 공유하는 정보도 없습니다. 광고, 분석 도구, 추적 기술을 사용하지 않습니다. 앱이 통신하는 유일한 외부 서비스는 사용자 본인의 계정에 접근하기 위한 Google API입니다.

5. 정보의 삭제

  • 앱 설정 화면에서 로그아웃하면 저장된 로그인 토큰이 즉시 삭제됩니다.
  • %APPDATA%\desk-widget\ 폴더를 삭제하면 로컬에 저장된 모든 데이터가 제거됩니다.
  • Google 계정 연결 관리에서 이 앱의 접근 권한을 언제든지 철회할 수 있습니다.

6. Google 사용자 데이터 정책

이 앱의 Google 사용자 데이터 사용은 제한적 사용 요건(Limited Use)을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. 데이터는 위젯에 기능을 제공하는 목적으로만 사용됩니다.
