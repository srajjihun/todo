# 데스크톱 위젯 — 캘린더 · 할 일 · 포커스

바탕화면 우측 하단에 상주하는 위젯입니다.

- **캘린더 탭**: Win11 달력 스타일 월 달력. 날짜를 클릭하면 아래에 그날의 일정 목록이 나오고, ＋ 버튼으로 일정을 추가합니다.
- **할 일 탭**: `+ 할일 추가` 입력, 마감일별 그룹(기한 초과/오늘/예정/…), 체크로 완료. 기한 초과는 `연기` 버튼으로 오늘로 일괄 연기.
- **포커스 탭**: 뽀모도로 타이머 (기본 25분 집중 / 5분 휴식, 설정에서 변경). 집중할 할 일을 골라두면 그 제목이 타이머에 표시됩니다.
- **포커스 미니 창**: 화면 우상단에 뜨는 작은 타이머 카드. 메인 위젯과 **별개로** 최상단 고정을 켜고 끌 수 있어, 위젯을 고정하지 않아도 타이머만 항상 위에 띄울 수 있습니다. (포커스 탭의 `미니 창 열기` 또는 트레이 메뉴)
- **구글 동기화**: Google 캘린더·Google Tasks와 양방향 동기화. 오프라인에서 만든 항목은 대기열에 쌓였다가 자동 반영.
- 📌 버튼: 항상 위(최상단) 고정 토글 · 헤더 드래그로 이동 · **가장자리를 끌어 크기 조절** · ✕는 숨기기(트레이에서 복원) · 종료는 트레이 메뉴에서.

## 설치해서 쓰기 (권장)

설치 파일을 만들면 시작 메뉴와 바탕화면에 바로가기가 생겨, 종료한 뒤에도 언제든 다시 켤 수 있습니다.

```bash
npm install
npm run dist
```

`dist\Desk Widget Setup <버전>.exe` 를 실행해 설치하세요.

## 개발 모드로 실행

```bash
npm install
npm start
```

## 구조

- `src/main/` — Electron 메인 프로세스 (창/트레이/OAuth/동기화 엔진/뽀모도로 타이머)
- `src/renderer/` — UI (바닐라 JS, 탭 3개 + 설정)
- `src/preload.js` — contextBridge로 노출하는 IPC 표면
- 데이터 저장 위치: `%APPDATA%\desk-widget\` (settings/tokens/cache/pending.json)
  - 리프레시 토큰은 Windows DPAPI로 암호화 저장됩니다.
